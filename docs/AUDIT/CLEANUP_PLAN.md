# CLEANUP_PLAN.md

1.  **Repozytorium:** Stworzenie folderu `src/` z podziałem na `server/`, `client/`, `shared/`.
2.  **Zależności:** Usunięcie zbędnych pakietów z `package.json` (np. `@aws-sdk`, `@openai`, etc.).
3.  **Projekt:** Ekstrakcja wszystkich skryptów z `.rbxl` do odpowiednich plików `.luau`.
4.  **Konfiguracja:** Ujednolicenie `.welcome.conf` i `_config.yml`.
